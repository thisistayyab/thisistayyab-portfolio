# Tayyab Portfolio (Next.js)

Production portfolio for [thisistayyab.dev](https://thisistayyab.dev) — static pages plus a **Supabase-backed blog** and admin CMS.

## Local development

```bash
npm install
cp .env.example .env.local
# Fill in Supabase + EmailJS values (see vercel.env.example)
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- Blog: `/blog`
- Admin: `/login` → `/dashboard/blog`

## Deploy on Vercel

1. Push this repo to GitHub and [import the project on Vercel](https://vercel.com/new).
2. **Framework preset:** Next.js (auto-detected; `vercel.json` is included).
3. **Environment variables:** add every key from [`vercel.env.example`](./vercel.env.example) under **Project → Settings → Environment Variables** (Production + Preview at minimum).
4. **Domain:** attach `thisistayyab.dev` in **Project → Settings → Domains** (DNS as Vercel instructs).
5. Deploy. `/sitemap.xml` and `/robots.txt` are generated by the App Router (`app/sitemap.ts`, `app/robots.ts`).

### Vercel files in this repo

| File | Purpose |
|------|---------|
| [`vercel.json`](./vercel.json) | Security/cache headers (sitemap, images, `llms.txt`) |
| [`.vercelignore`](./.vercelignore) | Excludes `portfolio old` from uploads |
| [`.node-version`](./.node-version) | Node 20 for builds |
| [`vercel.env.example`](./vercel.env.example) | Env vars to paste into Vercel dashboard |

### After deploy

- Submit `https://thisistayyab.dev/sitemap.xml` in [Google Search Console](https://search.google.com/search-console).
- Publish posts from `/dashboard/blog`; ISR refreshes public pages within ~5 minutes.
